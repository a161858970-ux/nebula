# Music Nebula — Z1 穿梭歌词系统设计规格

> 用途：Z1 歌词层（`src/components/LyricsLayer.tsx`）的现状设计总览，含空间参数、生命周期与**已废弃决策**。
> 本系统经历过十几轮迭代打磨，改动前必读；参数以本文件 + 代码注释为准，改参数需同步两处。
> 维护：本文件有修改时同步追加 `CHANGE_LOG.md`。

---

## 1. 定位与底层法则

- Z1 = 空域穿梭歌词层，与 Z2 卡片星云并行；`layerMode` 可切到 Z2 之上（Z1 overlay）。
- **底层法则（用户多次强调，本系统一切逻辑的出发点）**：歌词播放沿时间推进，但视觉是多句并行。设计歌词逻辑时不能只按传统垂直滚播考虑"当前句时间状态"，必须同时计算前后 1–2 句与已发生状态来调整整个匹配系统。
- 当前实现为**三身份带状系统**（v2），取代早期纯随机斜向穿梭——保留空间流动感，但强制建立可预期的三句结构，优先保证前瞻可读性。

---

## 2. 三身份结构

- 全局最多 `current / next / nextNext` 三句活跃身份，随播放时间实时推进；开头 / 结尾不足三句时优雅降级，不补空位。
- `current`：正在演唱，逐字高亮，视觉最强；`next`：下一句，已就位等候；`nextNext`：下下句，就位或正在进入。
- 身份切换 = 上一句变 `leaving`、下一句晋升 `current`、再下一句补位 `next`。

---

## 3. 空间带（半动态带状）

| 角色 | 位置 | 参数（代码常量） |
| --- | --- | --- |
| current | 画面垂直中心 ±12%（最舒适阅读区） | `MAIN_Y = 0.5` |
| next | 主带上方 18%–28% 高度（布局一）；布局二上下随机 | `NEXT_MAG = [0.18, 0.28]` |
| nextNext | 再向外 34%–48%（夹在可视区内） | `NEXTNEXT_MAG = [0.34, 0.48]` |
| 水平错位 | 8%–18% 视口宽，随机方向（一左一右或同向轻错） | `X_OFF = [0.08, 0.18]` |

- 布局一：当前句在最下、候句依次在上；布局二：一上一下随机错落。设置项「歌词布局」。
- **防扎堆平衡器**：`balanceRef` 记录连续落点倾向，避免候选句连续几十句全扎同一侧（曾实测出现半首歌全在右侧的 bug，已修）。
- 区域随窗口大小实时计算，保持比例稳定。

---

## 4. 生命周期

1. **入场**：左右斜向为主，垂直入场概率 12%（`VERTICAL_P = 0.12`）；飞行 1.1–1.7s 缓入（`entryDur = clamp(rand(1.1,1.7), 0.6, timeToStart×0.85)`）；透明度 0→目标；角度从较大收到等候态；垂直入场维持自身微水平方向。
2. **稳定期**：current 仅做「保护性水平微调」（防当前字过度靠边，不积极追字）；next / nextNext 呼吸漂浮——`sin(simT×1.4 + phase) × 视口宽 1.2%` 级别的缓慢上下 + 左右游移。
3. **晋升**：next → current，短距滑入主带（0.6–0.9s 量级、平滑缓出）；水平偏移收窄到中心 ±3% 视口宽；字号放大、透明度拉满、角度收小、开始逐字高亮。体感是"自然接过焦点"，不是被甩到中间。
4. **离开**：左右各 50% 随机；斜向飞出屏幕（向量整体旋转 ±1.5°–5° 小角度，非纯水平）；1.0–1.4s；轻微减速（`ease = 1 - 0.35×exitT`）；**不做整句淡化**，保持实体飞出；左出目标按"句尾越过左边界"计算（`-MARGIN×2 - wPx`），修复过句尾未出屏即被回收的 bug。
5. **交接重叠**：当前句离开与下一句晋升重叠约 0.3s，形成自然衔接。
6. **当前句进入最后 25%–30% 时长**：冻结水平微调，提前确定离开方向并做几乎不可察的预偏。
7. **暂停**：停止所有位移与漂浮推进，保持当前视觉状态；**Seek**：按新时间重算三句身份，平滑补飞 / 多余句子快速离场；**切歌**：立即清空全部飞行对象与身份。

---

## 5. 逐字高亮

- 有 YRC / QRC 字级时间轴：按字映射到整句水平区间 `[p0, p1]`，区间内按时间插值得到连续 `progress`；`--wp` 按需写入——**过去句只写一次 1**，当前句 / 切换帧才更新（性能优化，修复过逐字重影）。
- 软羽化扫字：`smoothstep` 柔边过渡，`--feather` 逐字 0.03 / 整句 0.055（无字级时间轴时用更大值）；进度线附近叠加柔光，禁止硬切 if。
- 上浮模式：`--lyric-rise`（`wordRise` 设置项）逐字轻微上浮微弹（translateY / scale），增强"吐字"感；已唱字额外轻 `translateY(-2px)` 微弹。
- 无 YRC：整句按 duration 线性 / 缓动推进（已知边界：长句后半段会显得拖）。
- 模式切换：清空 `--wp/--feather` 写入缓存强制全量重写（修复过扫光/上浮模式切换后失效）。
- 换字目标变化带阻尼 / 进度 15%–85% 区间内用力拉、两端放松（避免整句被"拉着跑"晃动）。

---

## 6. 赋色与视觉层级

- 三色系统 `primary / secondary / highlight`（`lib/coverColors.ts`）：从**当前背景媒体**（封面 / 自定义上传 / Wallpaper）实时采样，非固定按歌曲封面；近单色银蓝兜底（`SILVER_BLUE`）；最低亮度保护（普通句 ≥0.34–0.38、高亮句 ≥0.48）；逐字高亮带轻微发光。
- 自定义颜色也走同一套 primary/secondary/highlight 生成逻辑，保持同色系双层效果（`lyricColorSource` 设置）。
- 视觉层级（必须拉开，否则三句糊成一团）：current 最大最亮最实、角度 ±8°–14°；next 中等（opacity 0.62）；nextNext 更小更透（0.42）、角度可稍大；leaving 0.95。
- 当前句放大系数（`currentScale`）与逐字上浮幅度（`wordRise`）暴露在歌词设置页可调。
- **翻译只作用于二级播放页**（NowPlayingPanel）；Z1 穿梭仅显示原文，不显示翻译。

---

## 7. 安全区与朝向（历史修复沉淀）

- 底部安全区：**只对左右发出的水平小倾角歌词生效**，收敛到播放条处（下方空间被播放条压缩）；大斜率与垂直入场不受限，可正常穿过播放条。
- 大斜率 / 垂直入场收紧四角安全区（避免可见三角形过小、歌词大部分出屏）。
- 垂直入场朝向：句子主体在右半边 → 文字朝左；左半边 → 朝右（不旋转文字本身，只按半区决定读取方向，字不朝外）。
- 垂直安全 clamp：`ch×0.06 ~ ch×0.94`；水平安全随句宽实时收拢（右侧句末不触碰边缘）。
