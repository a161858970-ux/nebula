# Music Nebula · 音乐星云

> **A visual music player where music becomes space.**
> Electron + React 的桌面端 3D 音乐星云播放器 —— 音乐改变空间，空间表达音乐。

> ⚠️ **开发期 README**：项目仍在半成品阶段（v0.1.0），功能、界面与平台接口都在持续迭代；本文档会随进度更新，最终版在 CI/CD 阶段定稿。

---

## 这是什么

Music Nebula 不是传统的列表式播放器，而是一个**音乐可视化空间**：

- 主界面是一片 3D 卡片星云 —— 上千张歌曲卡片按「中心密、四周稀」散落，靠近视口中心自动放大变亮，边缘衰减并模糊（鱼眼），可无限拖拽漫游；
- 歌词是空间中的穿行文字，而不是底部字幕条；
- 歌单、音源、歌词、评论**跨平台统一接入**，音源失败会自动跨平台兜底；
- 正在推进的「听音空间」重构，会把播放体验从一条播放条扩展为一个安静的第二聆听环境。

## 功能一览

### 播放与队列
- 全局单例播放器：播放 / 暂停 / 上一首 / 下一首 / 进度拖动 / 音量滚轮与滑杆；
- 三种播放模式：顺序 / 单曲循环 / 随机（随机为整轮洗牌不重复）；
- 「下一首播放」：右键任意歌曲插入播放队列（不打断当前播放）；
- 播放队列面板（当前项 + 即将播放、点击跳播、移除即将播放项、多首按「先添加先播放」排序）—— 随播放器重构分支开发中，尚未合入 `main`；
- 音质选择：按已登录账号的会员等级自动匹配可用档位（标准 / 极高 / 无损 / Hi-Res / 臻品等）；
- 播放失败自动跳过并置灰卡片，试听片段（VIP 未覆盖）有明确标记。

### 歌词系统
- **穿行歌词层**：三句身份机（当前 / 下一句 / 下下句），逐字高亮、软羽化扫字、上浮模式，参数可在设置中调节；
- **二级窗口歌词**：上下分区同句高亮 + 翻译跟随；
- 字级时间轴支持网易云 YRC 与 QQ QRC，无字级数据时按整句进度兜底；
- 翻译开关、歌词字号、高亮风格、布局、取色源（封面取色 / 自定义）、加粗等 DIY 项。

### 内容浏览
- 全网搜索（歌曲 / 歌手），支持网络歌曲**临时点播**（不打断当前歌单，播完自动接回）；
- 歌曲详情：封面、歌手、专辑、发行时间、制作团队（从歌词元数据提取）；
- 歌手主页：头像 / 简介 / 热门歌曲 / 专辑墙，可进入「全部歌曲」全量列表；
- 专辑页：专辑信息 + 完整曲目，可直接点播；
- 评论页：热门 + 最新，支持分页「加载更多」。

### 背景与氛围
- 背景模式：跟随封面（多模式）/ 自定义图片 / 壁纸库 / 午夜备用；
- 从当前背景媒体实时取色，驱动全局光照与歌词三色调色板（主色 / 次色 / 高亮），近单色封面回退银蓝。

### 界面与设置
- 边缘感应 HUD：鼠标触顶滑入搜索栏，左右两侧为歌单导入 Dock 与账号 / 设置 Dock（小球 → 胶囊 → 窗口的连续变形）；
- 沉浸开关：隐藏卡片层 / 隐藏歌词层；
- 设置页：歌词设置 / 界面设置 / 背景设置 / 系统设置（播放器设置分组随重构加入）。

## 技术架构

**技术栈**：React 18.3 · TypeScript 5.6 · Vite 5（单文件构建）· Electron 43 · esbuild（主进程打包）· motion 13（动效）· music-metadata（本地音乐 ID3）· qrcode

**架构要点**

- **主进程即后端**：平台适配器（Adapter）统一抽象 `fetchPlaylist / fetchSongUrl / fetchLyric / fetchComments / 歌手 / 专辑 / 搜索`，渲染进程只能通过 `contextBridge` 暴露的 IPC 调用；
- **领域化前端**：11 个领域 hooks（账号 / 曲库 / 歌单 / 导入 / 浮层 / 歌词 / 背景 / 界面设置 / 搜索 / 边缘面板 / 舞台）+ 2 个 service，仅 3 个 Context（Playback / InterfaceSettings / VisualAtmosphere），依赖规则由 `scripts/check-arch.mjs` 机制化强制；
- **音源兜底链路**：主平台取链 → 失败则按已登录账号 VIP 状态跨平台路由（标题 + 时长 + 歌手三重校验，防翻唱 / 盗版）→ 统一经本地 `AudioProxy` 注入 Referer/UA 播放；
- **材质可换**：所有材质与动效参数走 CSS 变量（`--ui-*` / `--mat-*`），为未来「液态玻璃」第二套主题预留，切换主题不重写组件；
- **工程门禁**：每次改动 `build` + 自动化 QA 全绿后提交，架构依赖由守卫脚本拦截违规。

```
music-nebula/
├─ src/
│  ├─ main/          # 主进程后端（适配器 / 登录 / 加密 / 歌词解析 / 兜底服务 / IPC）
│  ├─ components/    # 视图区块（星云舞台 / 歌词层 / Dock / 浮层 / 播放器）
│  ├─ hooks/         # 11 个领域 hooks
│  └─ lib/           # 播放器单例 / 曲库服务 / 鱼眼 / 布局 / 取色 / 平移引擎
├─ electron/         # Electron 主进程与 preload（窗口、网络拦截、登录接线）
├─ scripts/          # 后端冒烟 / 前端 QA / 架构守卫 / 在线链路检查
└─ docs/             # 项目文档（project / design / meta 三类）
```

## 快速开始

**环境要求**：Node.js 18+（推荐 20+）· pnpm · Windows / macOS 桌面环境

```bash
pnpm install

# 构建并启动桌面版
pnpm build:desktop     # 构建渲染进程 dist + 主进程 dist-main
pnpm desktop           # 环境自检后启动 Electron

# 开发模式（浏览器内预览，桌面能力自动降级）
pnpm dev
```

**可选环境变量**

| 变量 | 用途 |
|---|---|
| `SPOTIFY_CLIENT_ID` | Spotify OAuth 登录（未配置时该入口提示不可用） |

**说明**

- `pnpm build` 的产物在仓库外的 `../../outputs/music-nebula/`（QA / 预览用）；桌面版请用 `pnpm build:desktop`；
- 修改 `src/main/` 后必须重新 `pnpm build:main`，否则 Electron 与冒烟测试仍走旧的 `dist-main/index.cjs`；
- Windows PowerShell 下 pnpm 建议带 `$env:pnpm_config_verify_deps_before_run='false'`；
- 登录凭证保存在本机 Electron `userData` 目录，**不会**上传到任何第三方。

## 质量保障

```bash
pnpm qa            # 前端自动化 QA（无头 Chrome：星云密度 / 鱼眼 / 平移回绕 / 播放 / 容错 / 设置）
pnpm qa:backend    # 后端冒烟（加密 / 歌词解析 / 字段映射 / 兜底 / IPC）
pnpm check:arch    # 架构依赖守卫
pnpm qa:live-new   # 在线链路验证（跨平台转译 / 歌手全曲 / 评论分页 / 头像）
pnpm qa:qq-live    # QQ 实账号链路验证（需自备 Cookie）
```

前端 QA 需要本机已安装 Chrome；所有改动要求 `build` + 相关 QA 全绿后再提交。

## 已知限制

- **平台接口易变**：本项目直接对接各平台 Web / 移动接口，平台风控、加密或接口调整都可能导致登录、歌单或取链失效；
- **汽水音乐不支持直接取链**（服务端按出口 IP 风控），播放依赖跨平台兜底；
- **VIP 与版权**：完整播放取决于**你自己账号**的会员状态；无版权或会员曲目可能只有试听片段或触发兜底搜索；
- 酷狗 / 汽水 / Spotify 的评论、Spotify 的歌手页尚未接入；
- Cookie 目前以明文 JSON 存储在本机（加密存储已在待办）；
- 项目处于开发中，界面与数据模型仍在迭代，不保证向后兼容。
